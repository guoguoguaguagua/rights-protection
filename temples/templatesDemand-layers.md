# 诉求分层模板

| 层级   | 内容                                  | 本次填写 |
| ------ | ------------------------------------- | -------- |
| 必须   | 解决本次问题、避免再犯、书面/短信确认 |          |
| 希望   | 道歉、合理补偿                        |          |
| 可放弃 | 额外赔偿、追责到具体人                |          |

## 止损线

- 再沟通超过 ______ 轮仍无进展，就接受确定方案。
- 对方拒绝提供工单号/短信确认时，不轻易接受口头和解。
- 核心问题未解决时，不接受“只给补偿不解决问题”。

## 示例（虚构）

- 必须：纠正异常扣费 + 工单号 + 短信确认到账时间；
- 希望：合理话费补偿 + 道歉；
- 可放弃：额外赔偿、追责到具体客服；
- 止损线：两轮沟通无进展，接受可验证的确定方案。
